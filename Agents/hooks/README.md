# SAMOVAR hooks

No lifecycle hooks are shipped or enabled in this initial bundle. The Skills
tasks allow an instruction-only MVP. A future hook must call a shared, tested
helper and have an explicit adapter for its IDE's event/payload protocol. Do not
copy one IDE's settings JSON to another or overwrite existing user settings.

Record its installation/consent and behavior tests alongside the corresponding
skill in `../skill-and-hook-testing/` before adding it to the installer.
