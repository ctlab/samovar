# Realistic example results

Figures and small tables produced by the realistic Slurm run
(`samovar_realistic/reprofiled_annotations*`). Regenerated with full true-taxid
F1 matrices (`--show_top 0`).

See the manual: [../../wiki/Realistic-Pipeline.md](../../wiki/Realistic-Pipeline.md).

| File | Description |
|------|-------------|
| `F1.png` / `F1_*.png` | Confusion matrices (all 22 true taxa on both axes) |
| `R2.png` / `R2_*.png` | Abundance R² |
| `CV_*.png` | Annotator cross-validation (full taxid space) |
| `roc_comparison.png` | ML ROC |
| `true_taxa_counts.csv` | Reads per true taxID |
| `combined_annotation_table_head.csv` | First 200 rows of the combined table |
